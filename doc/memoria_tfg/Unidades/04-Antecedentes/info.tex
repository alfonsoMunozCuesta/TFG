\chapter{Antecedentes}
\label{ch:antecedentes}

\paragraph*{}En este Trabajo Fin de Grado, el antecedente fundamental no es una línea amplia de trabajos previos, sino una aplicación concreta sobre la que se construye la ampliación realizada. Por ese motivo, este capítulo se centra en el sistema desarrollado por Lucía Cabezuelo Pérez, ya que constituye el punto de partida técnico, funcional y metodológico del presente proyecto. Las referencias generales al abandono universitario y al análisis de supervivencia se desarrollan en el marco teórico, mientras que aquí interesa describir qué ofrecía el dashboard base, qué funcionalidades estaban ya disponibles y qué margen de mejora dejaba abierto.

\paragraph*{}El trabajo previo corresponde al Trabajo Fin de Grado de Lucía Cabezuelo Pérez (2025), titulado \textit{``Análisis, Diseño e Implementación de un Dashboard Interactivo para el Análisis de Supervivencia aplicado al Abandono Escolar Universitario''}. En él se desarrolló una aplicación web en Python y Dash orientada a facilitar el análisis de datos académicos sin exigir al usuario conocimientos avanzados de programación. La aplicación permitía cargar un archivo CSV, mostrar el conjunto de datos original, ejecutar un proceso de limpieza y trabajar posteriormente con un dataset preparado para el análisis. Esta primera pantalla, mostrada en la Figura~\ref{fig:lucia_inicio}, refleja ya la idea central del sistema: concentrar el flujo de carga, preprocesamiento y análisis dentro de una interfaz web sencilla.

\paragraph*{}Una vez cargados los datos, el dashboard organizaba la exploración en varios apartados. Por un lado, incluía una sección de visualización del dataset, útil para comprobar el contenido de los datos antes y después de la limpieza. Por otro, incorporaba un análisis de covariables que permitía observar la distribución de variables relevantes para el abandono universitario. El núcleo funcional se encontraba en la sección de análisis de supervivencia, donde el usuario podía elegir entre tres técnicas: Kaplan-Meier, regresión de Cox y Test de Log-Rank, como se muestra en la Figura~\ref{fig:lucia_supervivencia}. Esta organización hacía que el usuario pudiera pasar de la revisión de datos a la generación de resultados estadísticos sin abandonar la propia aplicación.

\paragraph*{}Cada una de esas técnicas cubría una parte concreta del análisis. Kaplan-Meier permitía estimar la curva de supervivencia general y aplicar filtros por covariables como género o discapacidad, de forma que se pudieran comparar visualmente distintas trayectorias de permanencia. La regresión de Cox ofrecía una tabla de resultados con coeficientes, razones de riesgo y medidas de significación para estudiar la influencia de las variables seleccionadas. El Test de Log-Rank completaba el análisis comparando curvas entre grupos y ayudando a determinar si las diferencias observadas podían considerarse estadísticamente relevantes. En conjunto, el TFG de Lucía proporcionó una primera herramienta funcional para cargar datos, limpiarlos, seleccionar técnicas estadísticas y obtener resultados interpretables desde un entorno interactivo.

\paragraph*{}Además de los modelos estadísticos, una aportación relevante del sistema previo fue la integración de un módulo de inteligencia artificial basado en Llama 3 mediante Ollama \cite{ollama_llama3}. Este módulo actuaba como apoyo interpretativo: a partir de los resultados generados por la aplicación, el usuario podía solicitar una explicación textual que ayudara a entender la gráfica o la tabla obtenida. La Figura~\ref{fig:lucia_ia} muestra este tipo de interacción, en la que el sistema no se limita a presentar valores numéricos, sino que intenta traducirlos a una explicación más accesible para el usuario final.

\paragraph*{}No obstante, ese sistema también dejaba margen para nuevas ampliaciones. El conjunto de técnicas estaba centrado en los modelos clásicos principales, la interfaz dependía de un flujo todavía mejorable y la interpretación mediante IA podía optimizarse en términos de rendimiento y despliegue local. También quedaban abiertas mejoras como la incorporación de nuevos modelos, la comparación entre técnicas, la exportación de resultados, el soporte multilingüe y una organización más completa de las funcionalidades. Por ello, el presente proyecto parte de esa base y amplía sus posibilidades: se incrementa el número de modelos estadísticos disponibles, se incorporan técnicas de aprendizaje automático aplicadas a la supervivencia, se sustituye el módulo de IA por una configuración local más ligera en el entorno de pruebas y se añaden soporte multilingüe, exportación de informes y una interfaz rediseñada. La finalidad no es rehacer el sistema previo, sino extenderlo de forma coherente y proporcionar más recursos para analizar e interpretar el abandono académico universitario.
